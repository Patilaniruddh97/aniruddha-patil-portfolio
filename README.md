# Aniruddha Patil — Portfolio

A responsive single-page portfolio UI based on the supplied resume.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static server.

## Before publishing
- Replace the placeholder LinkedIn `href="#"` with the real profile URL.
- Add the final PDF resume if you want a Resume button/download.
- Replace project links with the real GitHub repositories/demo URLs when available.
- Deploy the folder to Vercel, Netlify, GitHub Pages, or another static host.

The page uses Google Fonts (Inter + DM Mono) and otherwise has no external runtime dependencies.
